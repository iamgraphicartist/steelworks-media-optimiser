    Where the Dropbox desktop app keeps your synced files. If a video is already synced here, the app checks it straight away instead of downloading it, which makes matching much faster.

    1. Usually it's found automatically. If the field shows a grey Found automatically path, leave it empty.
    2. To check: click the Dropbox icon in the taskbar (Windows) or menu bar (Mac), then your profile picture, then Preferences › Sync. The path under Dropbox folder location is the one you want.
    3. Typical locations: E:\Steelworks Dropbox on Windows, or ~/Library/CloudStorage/Dropbox-Steelworks on a Mac.

    The client ID and secret come from a Figma OAuth app. One app is enough for the whole studio, so whoever makes it can share both values.

    1. Open the Figma developer page and sign in.
    2. Click Create a new app and name it Steelworks Media Optimiser.
    3. Under Callback URL, add this address exactly:
    4. Under Scopes, tick current_user:read, file_content:read and file_metadata:read. All three are read-only; the plugin makes the changes.
    5. Click Save, then copy the Client ID into this field and the Client secret into the next one.

    Shown on the same Figma app page as the client ID (see the steps above). Figma only shows it in full once. If nobody saved it, click Regenerate secret on that page and share the new one with the studio.

    It's stored in Windows' protected storage or the macOS Keychain, never in a plain file.

    The app key comes from a Dropbox app. One is enough for the whole studio. No secret is needed: each person signs in with their own Steelworks account.

    1. Open the Dropbox App Console and sign in with a Steelworks account.
    2. Click Create app, then choose Scoped access and Full Dropbox. Name it Steelworks Media Optimiser.
    3. On the Permissions tab, tick account_info.read, files.metadata.read, files.content.read and sharing.read, then click Submit.

    5. On the same tab, set Allow public clients (Implicit Grant & PKCE) to Allow.

    ffmpeg is the free tool that compresses videos and turns GIFs into MP4s. The Windows installer already includes it, so leave this empty unless the Connect page says Missing.

    1. Mac: install Homebrew if you don't have it, then run brew install ffmpeg in Terminal.
    2. Windows: run winget install Gyan.FFmpeg in PowerShell, or download a build.
    3. Restart the app. If it still isn't found, click Choose… and select the ffmpeg program (ffmpeg.exe on Windows). ffprobe must be in the same folder.
